# Smart Washing Machine Optimizer — Product Interface Sketch

## 1. Input Screen

------------------------------------------------
       SMART WASHING MACHINE OPTIMIZER
------------------------------------------------

Dirt Level:             [ 0 - 100 ]

Laundry Load:           [ 0.1 - 10 kg ]

Fabric Type:            [ Cotton / Synthetic /
                          Delicate / Wool ]

Water Availability:     [ Low / Medium / High ]

                 [ Generate Recommendation ]

------------------------------------------------

------------------------------------------------

## 3. User Workflow

1. User enters laundry details.
2. System validates all input values.
3. Decision engine processes the laundry conditions.
4. System generates recommended washing settings.
5. Results are displayed to the user.
6. Recommendations are compared with fixed-cycle baseline.

## 4. Design Notes

- Simple and beginner-friendly interface.
- Clear input fields and output values.
- Invalid inputs should display an error message.
- Baseline comparison should be visible.
- Resource savings must only be reported after actual
  calculations and evaluation.

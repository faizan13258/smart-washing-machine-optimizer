
# Dataset Information

## Project
Smart Washing Machine Decision & Resource Optimizer

## Dataset Requirements
The project requires at least 10,000 realistic washing scenarios.

## Input Features
- Dirt level
- Laundry load size
- Fabric type
- Water availability

## Output Features
- Wash time
- Water consumption
- Detergent quantity
- Spin speed

# Raw Data and Scenario Source

## Data origin
This project currently uses reproducibly generated washing-machine test scenarios.
No real-world washing-machine dataset or laboratory measurements are claimed.

## Generation
Scenarios are generated by `src/generate_test_scenarios.py` using a fixed random seed for reproducibility.

## Inputs and units
- `dirt_level`: integer from 0 to 100 (project-defined scale)
- `load_kg`: laundry load from 0.1 to 10.0 kg
- `fabric_type`: Cotton, Synthetic, Delicate, or Wool
- `water_availability`: Low, Medium, or High (categorical levels)

## Assumptions and limitations
The ranges and categories are simulated project assumptions, not official manufacturer specifications.
Generated scenarios are for testing and development; they are not real observations.
No external dataset licence is claimed because these scenarios are generated in this project.
